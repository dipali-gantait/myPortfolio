## 🖌️ How to Edit in Canva

All template files inside `assets/canva/` are written using standard SVG geometry and semantic vector text layers.

### Option A: Complete Master Design (Single Canvas)
1. Open [Canva](https://www.canva.com/).
2. Click **Create a design** > **Custom size** > Width: `1440px`, Height: `4200px` (or create a Website project).
3. Drag and drop `assets/canva/canva-master-full-portfolio.svg` directly onto the canvas.
4. **Right-click** on the imported design and click **Ungroup**.
5. Every single element (text box, gold dot, teal badge, button, and project card) is now **100% individually selectable, moveable, and editable in Canva**!

### Option B: Multi-Slide / Multi-Page Website
If you prefer a multi-slide or multi-page presentation / website layout in Canva:
- Page 1: Drag `canva-01-hero-profile.svg` (Header & Hero)
- Page 2: Drag `canva-02-experience.svg` (Timeline)
- Page 3: Drag `canva-03-projects.svg` (Project Cards)
- Page 4: Drag `canva-04-skills.svg` (Technical Skills Grid)
- Page 5: Drag `canva-05-education-hackathon.svg` (Education & Hackathon)
- Page 6: Drag `canva-06-contact-footer.svg` (Contact & Footer)
